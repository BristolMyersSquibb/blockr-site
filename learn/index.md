# Learn

Each tutorial builds one app in blockr. Start with the first one, the later
ones build on it. You need blockr installed, see [Install](/install).

1. [Build your first app](01-build-your-first-app): a filter feeding a scatter
   plot on the penguins dataset.
2. [Build a dashboard](02-build-a-dashboard): a chart your users can click, and
   a table that follows the click.
3. [Work with many tables](03-many-tables): load a data model of linked tables,
   flatten it into one table, and chart it.
4. [Custom code](04-custom-code): run your own R function as a step in the
   workflow.
5. [Create a custom block](05-create-a-block): turn a function you use often
   into a block of its own, with a coding agent or by hand.

To try blockr without installing it, open the
[playground](https://blockr.cloud/app/empty) or one of the
[examples](/examples/).
