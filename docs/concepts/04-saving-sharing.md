# Saving and sharing

A board saves as one unit: blocks, links, layout and visibility toggles.

- **Save** (navbar) opens a menu. "Save…" (Cmd/Ctrl+S) stores the board under a name; the label next to the menu says whether the current state is saved. Once the board is saved, "Version history" in the same menu lists its earlier saves.
- **The board name** at the left of the navbar opens the workflow list: search and reopen any saved board, or open "All workflows". "New workflow" starts a fresh board in place, "New in a new tab" opens one in a new browser tab.

Storage is a pins board: local when you run blockr yourself, per-user on Posit Connect. On Connect the Save menu gains "Share…", where you set a saved workflow's visibility and share it with other users.

Details and backend options: [blockr.session](https://github.com/BristolMyersSquibb/blockr.session).
